# bottle-flip

A physics-based mobile & web Bottle Flip game built with Matter.js, HTML5 Canvas, DeviceMotionEvent accelerometer sensing, and Web Audio API synthesizer.

## Features
- **Physics Engine:** Powered by Matter.js with customizable liquid fill levels (0%, 25%, 50%, 75%, 100%) that dynamically alter center-of-mass stability.
- **Controls:** Supports physical device motion flicking (iOS 13+ permission modal included) and desktop/touch drag-and-swipe gestures with trajectory prediction.
- **Visuals:** Photorealistic 3D-style water bottle rendering, studio lighting, wooden table with perspective legs, sloshing liquid physics, and particle effects.
- **Audio:** Latency-free Web Audio API synthesizer for flick whooshes, landing thuds, crash sounds, and combo streak chime fanfares.

## Getting Started
```bash
npm install
npm run dev
```
